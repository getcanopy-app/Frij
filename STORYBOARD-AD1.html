Production notes

Shoot order (≈20 min total): 1) Stock check — make sure steak/eggs/cream are actually in the fridge. 2) Film F1, F2, F3 in one take each (phone vertical, lock exposure by long-pressing on the fridge interior). 3) Do the screen recording for F4–F6 in one continuous take: Control Center → Screen Record → open Frij → scan → generate. Regenerate off-camera first until the trio is drool-worthy, then record a clean run. 4) F7 while cooking dinner anyway. 5) F8 is a still frame — make it in any editor.

Edit: CapCut (free, made for this). Import all clips → trim to the timecodes above → burn captions with the exact overlay text (use a bold system-style font, bottom third, black box white text) → speed-ramp F4 if needed → export 1080×1920, 30fps.

Lighting: kitchen lights ON plus the fridge's own light. Avoid backlit windows behind you in F3.

The one thing that matters most: F1's text must be readable in under 1.5 seconds and the fridge must look like a real person's. Everything else is forgivable.
